# AMY Predictive QRR — Monthly ATR Walk-Forward Backtest

## Scope

- Instrument: XAUUSD
- Timeframe: M5
- Data: January 2022 through June 2026
- Candles: 311,817
- Initial capital: $2,000
- Risk: 1% of current balance per closed trade
- Maximum SL: 150 pips, using 1 pip = 0.10 price
- Costs: spread, commission, swap, and slippage excluded

## Monthly correction process

For each RR profile separately:

1. January 2022 starts with the original indicator parameters.
2. The parameters entering a month are the corrected code produced from the previous month.
3. The current month is backtested first without using its data to change the starting code. This is the walk-forward result reported below.
4. ATR Length, zone width ATR, approach ATR, merge ATR, invalidation ATR, and SL buffer ATR are repeatedly adjusted on that month.
5. The corrected parameter set is carried into the following month.
6. Signals whose SL distance exceeds 150 pips are skipped.
7. Entry is locked after candle close. The signal candle cannot hit TP or SL. If TP and SL are both touched by the same later candle, SL is counted first.

## Interpretation boundary

The monthly optimized columns in the CSV are in-sample diagnostics. They are not the valid performance result. The valid sequential result is the `before_*` set, because it uses only the correction generated by the preceding month.

The reported maximum drawdown is calculated from month-end compounded balances. The exact trade-by-trade continuous drawdown can be higher. The corrected Pine file has not been compiled inside TradingView.
